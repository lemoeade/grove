# 术语

界面文案、README、CHANGELOG、代码注释里说到同一样东西时用同一个词。**以界面为准**：下面的词都是 `internal/i18n/zh-CN.json`
里实际出现的写法（英文界面的译法在 `en.json`）。界面改了叫法，这张表和 README 一起改；新加的概念先在这里定词。

## Git

| 概念 | 用这个词 | 别写成 |
|---|---|---|
| index 里的改动 | 已暂存（组名"已暂存"；动作"暂存" / "取消暂存"） | 已缓存、staged |
| 工作区里没暂存的改动 | 未暂存（"未暂存的改动"） | 已修改、未缓存 |
| 没被跟踪的文件 | 未跟踪（"未跟踪的文件"）；Git 栏里和未暂存的同在"改动"一组 | 新文件、untracked |
| 按块 / 按行操作 | 暂存这一块、丢弃这一块、暂存选中的行 | hunk、局部暂存 |
| 撤掉工作区的改动 | 丢弃改动（`git restore` / `git clean`，先问） | 放弃改动、还原改动、回退 |
| stash | 贮藏、弹出贮藏、应用贮藏、丢弃贮藏 | 储藏、暂存（和 stage 撞了） |
| fetch / pull / push | 抓取 / 拉取 / 推送；强制推送；同步（拉取再推送） | 获取、拉、上传 |
| 领先 / 落后上游 | 领先 / 落后（↑ / ↓） | 超前、待推送 |
| cherry-pick / revert | 拣选 / 还原提交 | 挑选、回滚 |
| 进行中的合并、变基、拣选 | 中止 / 继续 / 跳过（Git 栏的横幅里） | 取消、恢复 |
| 冲突的两边 | 我的 / 他们的（"用我的""全部用他们的"） | ours / theirs、本地 / 远程 |
| 没有任何改动的仓库 | 工作区干净 | 无变更、clean |
| 工作树状态 | 需要你、等你、运行中、可合并、有改动、空闲、已合并 | — |
| git tag | 标签（新建标签…、删除标签） | tag（编辑器标签也叫标签，靠上下文分） |

## Diff

| 概念 | 用这个词 | 别写成 |
|---|---|---|
| 两栏对照 / 一栏 | 并排 / 统一（"统一 diff"） | 左右、分栏、内联 |
| 只显示改动附近 / 显示整个文件 | 只看改动附近 / 全文（"全文 diff"） | 局部、上下文 |

## 界面区域和编辑器

| 概念 | 用这个词 | 别写成 |
|---|---|---|
| 三栏 | 侧栏、右栏（历史）、底栏（终端 / 输出 / 问题） | 左边栏、面板区 |
| 侧栏的页 | 文件树、搜索、Git 栏、大纲；文件树上面一段"打开的编辑器" | 资源管理器、源代码管理 |
| 主区 | 编辑器区；左右分屏 / 上下分屏 | 编辑区（README 里两种都有，界面是"编辑器区"） |
| 单击打开、会被下一个换走的标签 / 双击或改过后留下的 | 预览标签 / 固定标签（"固定打开文件"） | 临时标签。注意界面上单说"预览"是 Markdown / SVG 预览 |
| 命令面板和快速打开 | 命令面板、快速打开、跳到符号 | 命令选项板 |
| 每次保存留的快照 | 本地历史 | 时间线 |
| 按名字找的导航 | 跳到定义、查找引用、悬停时显示定义 | 转到定义、查找所有引用 |
