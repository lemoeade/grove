# Documentation

Development conventions and common commands are in [AGENTS.md](../AGENTS.md) at the repo root. The docs here go into
specifics:

- [architecture.md](architecture.md): architecture overview — layers and dependencies, what each package does, threads
  and state, development conventions
  - [architecture/](architecture/): details per subsystem (App and commands, state files, Git, staging, file tree,
    editor, Markdown, terminal, appearance)
- [testing.md](testing.md): how testing is split up, which tests cover the acceptance criteria, and how to measure
  memory
- [release.md](release.md): versioning rules, builds, DMG packaging, signing, notarization, the release pipeline,
  auto-updates and CI
- [shortcuts.md](shortcuts.md): the full shortcut table, generated from the command registry
  (`TestShortcutDoc -update`); don't edit it by hand
- [mygo-pitfalls.md](mygo-pitfalls.md): problems hit during development and how they were handled, in sections by topic
  (layout, lists, keyboard, editor, terminal, Git, …)
- [terms.md](terms.md): glossary of UI terms (English ↔ Chinese); README, CHANGELOG and comments follow it

`screenshots/` holds the screenshots used by the README; they are generated by `TestScreenshot`, then picked and copied
here.
